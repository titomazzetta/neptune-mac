# Code of conduct

Neptune is a small project, and the rules are short.

**Be useful and be decent.** Critique code, findings and decisions as hard as
they deserve; never the person who wrote them. Assume good faith, say what you
would change, and show your evidence — the same standard the tool holds itself
to.

**Not acceptable:** harassment, personal attacks, discriminatory language,
publishing someone's private information (including an unsanitized Neptune
report from someone else's machine), or sustained disruption of discussion.

**Security reports stay private** until a fix is released — use the private
vulnerability report linked from the new-issue page, not a public issue.

**Enforcement:** the maintainer may edit or remove comments, close issues, or
block participants who break these rules. To report a problem, use the private
report link or contact the maintainer through the GitHub profile.

This follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.
