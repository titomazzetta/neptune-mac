# Drop the ten Neptune scripts here

Copy your current Neptune `.sh` files into this folder before pushing:

    neptune.sh  sentry.sh  redflag_scan.sh  audit_system.sh
    network_check.sh  netcheck_plus.sh  check_updates.sh
    uninstall.sh  remove_mackeeper.sh

Then: `chmod +x *.sh` and commit. CI will lint them on push.
